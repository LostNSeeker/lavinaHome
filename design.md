## Body Font

* DM Sans

---

# Design Language

The entire website should communicate:

* Luxury
* Calm
* Scandinavian
* Editorial
* Boutique
* Organic
* Premium craftsmanship
* Natural materials

Avoid:

* Bright colors
* Glassmorphism
* Heavy gradients
* Thick shadows
* Neon colors
* Busy layouts
* Rounded cartoon elements

---

# Image Style

Only use:

* Natural lighting
* Warm interiors
* Wooden furniture
* Linen fabrics
* Neutral carpets
* Cozy homes

Avoid:

* Colorful rooms
* Artificial renders
* Busy backgrounds

# Animation Style

Everything should feel smooth.

### Hero

* Fade
* Scale 1 → 1.05
* Slow image zoom

---

### Scroll

Fade Up

```
opacity

0 → 1

translateY

40px → 0

Duration

700ms
```

---

### Collection Slider

Horizontal movement.

Smooth.

Snap scrolling.

---

### Hover

```
Scale

1 → 1.03

Transition

300ms
```

Images zoom slightly.
